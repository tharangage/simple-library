# UI design (Figma)

UI designs live in Figma. This folder records where each file is and what it covers, so the links
and design decisions are versioned with the code.

| Design | Figma file | Screens | Status |
|---|---|---|---|
| [Self-registration](self-registration.md) | [Simple Library – Self-Registration](https://www.figma.com/design/napnNlVd3hy0LtHqzMtQtA) | Default, validation errors, success (desktop) | Draft |

## Conventions
- One Figma file per feature; one doc here per Figma file (`<feature>.md`).
- Record the file link, frame names with node IDs, field-to-backend mapping and open questions.
- Figma files are in the owner's drafts and **private by default**. Share access in Figma before handing the link to others.
- The React app is **JavaScript only, never TypeScript**. Implement designs in JS components.
